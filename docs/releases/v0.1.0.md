# TraceClause v0.1.0 — First public preview

TraceClause is a local document evidence review workbench that connects requirements, response passages and human decisions with source references and rationales.

## Available in this release

- PDF, DOCX, TXT and Markdown import, extraction and source locations.
- Explainable BM25 retrieval with candidate, possible-conflict and missing-evidence hints.
- Manual evidence selection, saved decisions, history and stale-update protection.
- Markdown reports, CSV checklists, JSON snapshots and original-file downloads.
- Chinese application interface, synthetic examples and English documentation.

## Try it

Use Python 3.11+ and follow the [quick start](https://github.com/LingxiangXu/traceclause#quick-start). Open the local page and choose the demo action. No model API key is required.

## Validation and limitations

The application's 25 tests passed across Windows/Linux and Python 3.11/3.13. On ten development examples, first evidence hit rate is 7/9 and hint agreement is 8/10. Two paraphrase failures are retained. This is not an independent dataset and does not establish real-world accuracy.

OCR, semantic retrieval, version-impact analysis and multi-user authentication are not implemented. Use a trusted local, single-user environment. Docker build/runtime has not been validated. Automatic matches provide candidates; humans make decisions.
